# Trophy Buddy API · Spring Boot

A Java REST API for Trophy Buddy. It imports public PlayStation game libraries and trophy progress, enriches game details with IGDB metadata and curated guides, and stores results in PostgreSQL.

[Frontend repository](https://github.com/ricardobalbinot/trophy-buddy) · [Python implementation](https://github.com/ricardobalbinot/trophy-buddy-api)

## What the service does

- Resolves public profiles by PSN Online ID and imports their avatars, trophy totals, game libraries, and progress.
- Verifies Firebase ID tokens and scopes each saved library to the authenticated user's UID.
- Publishes each library snapshot in a single database transaction. Database leases coordinate concurrent imports, and failed imports preserve the last successful snapshot.
- Stores shared trophy definitions separately from player progress and reuses game details for the current library snapshot.
- Looks up optional IGDB metadata and associates available guides with the correct game edition and trophy set.
- Provides operator commands for guide index imports, manual review, and publishing curated trophy resources.

## Run locally

Use JDK 21 and PostgreSQL. Create an empty local database for the Spring application and set these environment variables before starting it.

| Variable | Purpose |
| --- | --- |
| `JDBC_DATABASE_URL` | JDBC URL such as `jdbc:postgresql://localhost:5433/trophy_buddy_spring` |
| `DB_USER`, `DB_PASSWORD` | PostgreSQL credentials |
| `FLYWAY_ENABLED` | Set to `true` to initialize a fresh Spring database and apply migrations |
| `FIREBASE_PROJECT_ID` | Firebase project used by the frontend |
| `GOOGLE_APPLICATION_CREDENTIALS` | Local path to a Firebase Admin service account JSON file |
| `PSN_SERVICE_NPSSO` | Bootstrap credential for the dedicated PSN service account |
| `PSN_TOKEN_ENCRYPTION_KEY` | Stable Base64-encoded 32-byte key for encrypting stored PSN sessions |
| `IGDB_CLIENT_ID`, `IGDB_CLIENT_SECRET` | Optional IGDB credentials |
| `CORS_ORIGINS` | Comma-separated frontend origins. Defaults to `http://localhost:3000` |
| `PORT` | Local HTTP port. Defaults to `8081` |

Keep credentials outside the repository. For a local copy of the existing Python database at Alembic revision `e55ca287043a`, leave Flyway disabled. If both implementations use a shared PSN refresh session, run one writer.

```sh
./mvnw spring-boot:run
```

On Windows, use `.\mvnw.cmd spring-boot:run`. Open [Swagger UI](http://localhost:8081/docs) or fetch the [OpenAPI document](http://localhost:8081/openapi.json), both generated by the running Java service. To connect the React frontend, set its local `NEXT_PUBLIC_LIBRARY_API_URL` to `http://localhost:8081`.

## API overview

| Method and path | Purpose |
| --- | --- |
| `GET /healthz` and `GET /readyz` | Check process health and PostgreSQL readiness |
| `GET /api/v1/library` | Read the saved library |
| `GET /api/v1/library/statistics` | Read library statistics |
| `POST /api/v1/library/sync` | Import a public PSN profile by `onlineId` |
| `POST /api/v1/library/games/{game_id}` | Read trophy progress, catalogue data, and available guides |
| `GET /api/v1/catalog` | Look up public game metadata |

Library routes require a Firebase ID token as a bearer credential. The API derives the storage UID from the verified token.

## Checks

```sh
./mvnw spring-javaformat:apply
./mvnw verify
```

Maven validates formatting and Checkstyle rules before compilation. GitHub Actions runs the same verification with PostgreSQL 17 and the Flyway baseline. To run the write integration test locally, set `TROPHY_VERIFY_WRITES=true` and `FLYWAY_ENABLED=true` against a dedicated database whose name ends in `_spring_test`. The test inserts fixture rows and simulates the PSN provider. For read compatibility with an existing local database, set `TROPHY_VERIFY_EXISTING_LIBRARY=true` with Flyway disabled and an imported library.

## Guide administration

Build the executable JAR with `./mvnw package` and run the operator commands against your configured database.

```sh
java -jar target/trophy-buddy-api-spring-0.0.1-SNAPSHOT.jar --trophybuddy.guide-admin=import-index
java -jar target/trophy-buddy-api-spring-0.0.1-SNAPSHOT.jar --trophybuddy.guide-admin=list --game="ASTRO BOT"
```

Use `bind` with `--service`, `--set-id`, `--entry-id`, and `--rationale`. Use `add-resource` with `--service`, `--set-id`, `--trophy-id`, `--title`, `--source-name`, `--url`, `--kind`, and `--language`. Resources start as drafts. Use `--publish` after review and `--spoiler-safe` for resources that can be shown without a spoiler warning.
